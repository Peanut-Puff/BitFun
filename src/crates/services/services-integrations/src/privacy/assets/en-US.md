# BitFun Privacy Statement (Development Placeholder)

> This statement is for development and functional testing only. It must not be used for a production release.

BitFun processes application settings, project files, and session data locally as needed to operate. Data required by an online feature is sent only when you actively use that feature.

When you submit user feedback, its category and content are sent to the feedback service. You can choose to include a trace identifier, a hash of the current session identifier, and the client version for troubleshooting. Project content, chat content, terminal output, device model, operating system version, and language are not included with feedback.

Accepting this statement does not cause BitFun to upload local project files, chat content, terminal output, API keys, or authentication information. System permissions are requested only when the related feature is used.

You can view this statement again, consent, or withdraw consent from About BitFun. Withdrawing immediately switches the application to not-accepted mode without exiting, restarting, or deleting project files, local settings, session data, or feedback access credentials.

Before production release, Operations and Legal must replace this placeholder with the approved complete privacy statement and update the policy version, consent version, and document hashes.
